# えのたね

[公開サイトを開く](https://manabitane.jp/enotane/)

GitHub PagesはGitHub Actionsから公開します。`codex/enotane`へのpushで依存関係のインストール・検証・Viteの本番ビルドを実行し、`dist`だけを配信します。Pagesの公開元は「GitHub Actions」を選んでください。ソースのルートをブランチから直接配信すると、開発用TypeScriptを読み込めず白い画面になります。

小学生・絵の初心者向けの図工教材です。7モジュール・69レッスンを、アニメで見る → 本物の画材でためす → 気づく → 自分の表現に使う、の4つの入り口で使えます。ログインや採点はありません。

## 開く

```powershell
npm ci
npm run dev
```

[製品画面](http://127.0.0.1:5186/)と[開発確認ページ](http://127.0.0.1:5186/dev.html)があります。開発確認ページには元の3試作、全69台本のCanvas検証、道具一覧を残しています。本番ビルドにはdev.htmlや確認UIを含めません。

オフライン保存は本番ビルドで確認してください。

```powershell
npm run build
npm run preview
```

[本番ビルドの確認](http://127.0.0.1:5187/)で「オフラインで使う」を開き、必要な教材を明示的に保存します。アプリ本体と18枚のチャレンジ作例は共通キャッシュ、台本は選んで保存します。更新は表示されたボタンから行います。教材キャッシュの削除はスタンプ・設定・他アプリの保存を消しません。

## 使える機能

- 全69教材の検索・★別表示・お気に入り、おすすめ順の道と一覧
- 4つの学習段階、準備と安全、気づきの問い、先生メモ、任意のスタンプ
- 速さ・左きき・ふりがな・静止画表示・ローカル日本語音声の設定
- 先生のステップ止め・拡大表示、順序付き授業セットURL、行事・単元の逆引き
- 色まぜ・水の量・構図のラボ、6作品チャレンジと各3通りのオリジナル作例
- A4技法カード4枚／ページとためし描きシート、PNG、字幕付き無音動画
- 保存した教材のオフライン利用と、明示的なキャッシュ更新・削除

例：`/?lesson=W-11`、`/?set=W-05,W-11&mode=teacher&kiki=left`。URLの利き手指定は、保存設定を上書きしません。先生モードでは記録の保存が初期OFFです。

再生領域にフォーカスするとSpaceで再生・停止、←／→でステップ移動、Homeで最初へ、Rでもう一回、Sで速さ変更ができます。入力欄やボタンの通常操作を奪いません。

## 描画と教材データ

手・袖・手袋は描きません。道具だけを線の端へ合わせ、固定角度・影で表示します。元のP-02・C-09・W-11台本は変更せず、新しい66本を追加しています。O-06は実物の観察を促す抽象ガイドで、手形も描きません。

`src/engine`は決定的な台本コンパイル、画材・マスク・場面の描画、上限付きチェックポイントと復元を担当します。`src/content`は69件・本文・参照の実行時検証、`src/store/progress.ts`はブラウザ内の記録・設定、`src/app`は製品画面です。画材図示は実物の完全な再現ではありません。全教材の実物レビュー状況をデータに明記しています。

## 検証

```powershell
npm run validate
npm run typecheck
npm test
npm run build
npm run build:dev
npm run test:e2e
```

`test:e2e`は独立した一時プロファイルのヘッドレスEdgeを使います。通常利用中のブラウザやプロファイルは操作しません。5186の開発サーバーと5187の本番プレビューを起動し、全69描画・元3本の回帰・保存・URL・印刷・動画・オフラインを検証します。結果と画像は`docs/full-implementation/`に保存します。

実装と確認の詳細は[検証報告](docs/full-implementation/report.md)、道具のみへの変更履歴は[道具表示の報告](docs/tool-only/report.md)を参照してください。ビルドとコミットは公開操作ではありません。
