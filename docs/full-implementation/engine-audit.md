## 契約・コンパイル・再生

エンジンは42種類のアクションを明示的に実装しています。69本の親台本では40種類を使用し、`hand.move`と`wait`も既存互換の契約として保持しています。比較内の子台本はレッスン件数に加算していません。

`types.ts`、`schema.ts`、`compiler.ts`、`stage.ts`で契約と実行を揃え、未知のアクション・引数・素材を黙って無視しません。読み込み時の`parseScript`は入力を変更せず、複製に既定値を適用します。通常の台本は3〜8ステップ、各3〜8秒、合計20〜60秒です。有限数、論理ステージ1000×625内の座標、参照先、SVG命令、展開後の経路も検証します。上限は1ステップ96アクション、64領域、指定点4096、SVG512命令等、生成後は1アクション50000サンプルです。

同じ可変層・カメラ・道具・オブジェクトの時間重複を拒否します。異なる描画層でも1つの表示中の道具が同時に2本の描画を追う台本は拒否します。こすり出しは下準備の完了後、にじみは同ステップ内の先行drop完了後に限ります。

乱数は台本seed・step ID・action IDから決めます。経路を固定の接触点へ展開し、描画時刻までのサンプルだけを使用します。`Renderer.render(stepIndex, timeMs, options)`は絶対時刻からステップ開始状態を復元して描画するため、RAF回数による半透明の重ね増しを避けます。同一エンジン・台本・ブラウザー・内部解像度での再現性を検証し、別ブラウザー間のピクセル完全一致は保証していません。

## アクションの処理意味

| 契約 | 実際の処理 |

| `smudge` | `paint`の近傍色をアルファ重みで拾い、指定経路へ薄く重ねる。濡れた水彩の処理には`paint.soften`を分ける |

| `note.arrow / note.circle / note.label` | カメラ・左右反転に位置を合わせた一時的な注記。文字は正方向に表示 |

| `wait` | 状態を変更せず台本の観察時間を保つ |

## 描画層・マスク・保存状態

| 層 | 意味 |
|---|---|
| paper | seed固定の紙。作品の背景 |
| under | スクラッチ等の下地色 |
| paint | 乾いた線・色、追加技法の結果 |
| wet | 濡れた水彩の色。乾燥時にpaintへ移る |
| top | 削る対象の上塗り |
| wetMask | 水のある被覆。透明な水、にじみ、光、観察表示、乾燥に使用 |
| resistMask | クレヨンではじく被覆。作品には直接表示しない |
| frottageMask | 紙の下の凹凸に対応する模様。作品には直接表示しない |
| pencilMask | 消しゴムが対象にする鉛筆被覆。鉛筆消去のある台本だけ作る |

マスクと色は分離します。カメラ・道具とその出入りの進捗、濡れ領域、机上オブジェクト、グリッド、比較の選択・進捗は論理状態として複製・復元します。注記と道具は作品の色へ焼き込みません。追加マスクのない元3本では追加処理の分岐を使いません。

チェックポイントは層の不変参照を共有し、書き込むときだけCanvasを複製します。untouchedなunderは再読込・再描画しません。チェックポイントのLRU予算は48MiB、完成素材等のテンプレートは24MiBです。画像を無制限に各ステップへ複製しません。不要な一時Canvas、旧比較ペア、`dispose()`したRendererの資源を解放します。

`getStats()`はチェックポイント、テンプレート、紙、現在の層と表示Canvas、経路の概算、比較子Rendererの画素量を含む推定です。GPU・JSヒープ・ブラウザープロセスの実メモリ、全一時画像の同時ピーク、共有資源の正確な重複排除を測る値ではありません。道具形状・小さな影の共有キャッシュもこの値の外です。

`renderTo(target, includeOverlay=false)`は現在の状態・カメラ・利き手を指定Canvasへ直接合成し、PNGのencode/decodeを挟まず動画へ渡します。出力側は1000×625の論理Canvasを用意します。作品のみの出力では道具・注記・ガイドを除き、`includeOverlay=true`でそれらを含めます。

## 手を描かない道具表示

鉛筆・筆はユーザー指定のCanvas描画を使用し、接触点をローカル原点に置いて`TOOL_SCALE=0.8`、固定-55°で表示します。筆の穂先は現在の色、水は`#BFE3F2`です。寝かせたクレヨンは最初の描画線分に直角の固定角度とし、曲線中も追従回転させません。その他の道具も接触点を同じ原点に合わせます。fingerは不透明度0.6の白い円と輪郭だけで、指の解剖図を描きません。

道具の先端は「時刻までに実際に描いた最後のサンプル」に合わせるため、先端だけが線より先へ動きません。影は同じシルエットを右下(6,7)、持ち上げ時(12,14)、不透明度0.10で合成し、描き始めは150msで下ろします。入退場は右上の画面外へ400ms、ステップをまたぐ途中状態も保持します。`ctx.filter`は使用していません。

通常の`mirror: handedness`はステージ全体を左右反転します。`mirror: none`は作品を反転せず、道具だけを接触点の周りで反転します。注記の文字はどちらも正方向です。

## 比較の2つの経路

1. **台本内`compare`**：左右は別Renderer・別画像・別カメラを使用し、親アクションの0〜1進捗を各子台本の合計時間へ写します。子は1〜8ステップ、各3〜8秒、合計0秒超〜60秒。入れ子compareを禁止します。左右ラベルと配置は固定し、利き手は各子の中で反転します。次の比較へ切り替えると旧ペアを破棄します。比較を終えた状態は保持し、次の通常描画・scene・tool配置で解除します。
2. **UIの2教材比較**：2つのPlayerは共通RAFと共有操作で進め、各教材の異なるステップ長は保持します。一方が先生停止のstep-ended、他方がplayingでも、共有停止は両方を停止状態へ揃えます。完了側のstep-endedを維持して勝手に次へ進めません。共有再開は完了側を次ステップ、途中側をその位置から、同じ復元後のフレームで再開します。片側のloading/error、復元中は共有操作を無効にし、キーボード操作も古い状態へ割り込ませません。

Nodeテストは同じ物体の途中位置への戻り、紙・パレットの重なり、比較のカメラ独立性と共通時刻、旧比較資源の解放、ガイドの復元、力・混色・新経路、復元中操作の拒否等を確認しています。比較E2Eは異なる先生停止境界、片側loading、片側error、復元待ち中のキー操作の4ケースです。親から統合検証合格の連絡を受けています。最終15件の統合実行結果は全体報告で確認します。
