## O-06・M-07・K-02と主要な教育条件

**O-06「手の形」**は正式ID・タイトルを維持しています。ユーザーの「手を今後いっさい描かない」が設計書の見せ場より優先するため、「手袋の形から指を分ける」イラストは使いません。現在の台本で使うscene spriteはellipse / rectだけで、独立した抽象図形、離れた鉛筆線、曲がり位置の丸注記による観察ガイドです。材料・先生メモも、無理のない実物観察と長さ・曲がる所・重なりを言葉で比べる内容へ合わせています。`hand.enter/exit`は既存互換のアクション名であり、手を描く指定ではありません。手の描画が実画面にないことは親の表示検証を参照してください。

**M-07「マーブリング」**の準備例はニッカー「マーブリング・デコ6色ベーシック」と同製品の専用水溶液です。液と水の量は現物説明に従う文にし、通常の水彩と水だけで同じ結果になるとは説明していません。模様づくりは`marble.swirl`、紙への転写は`marble.transfer`を台本に明記。メーカーの[製品情報](https://nicker-enogu.com/product_cat/marbling)と[公式FAQ](https://nicker-enogu.com/contact/)は専用絵の具・液の必要を確認する資料です。年齢・換気・希釈・扱い・廃液は現物表示と学校ルールを確認する先生メモがあり、実物での模様の再現は未確認です。

**K-02「色の輪」**の最初の輪は`aka, daidai, kiiro, midori, ao, murasaki`の6有彩色を使います。白・黒・茶を色相の位置へ加えず、隣接色と向かいの色を比べる代表モデルです。モデルや画材で違うこと、全色の正確な混色予測ではないことを先生メモに記載。
